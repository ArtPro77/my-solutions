# Analysis of Problem 2252A

Idea: Let's find the longest block of identical elements in the array and count its length. For example:

7
10 10 10 8 8 8 8

Here, the longest block of identical elements is (8 8 8 8) consisting of 4 elements. Now the question is: How should we arrange the other elements so that the two 8's don't end up adjacent? The other elements here are the block (10 10 10).

The optimal arrangement would be:
8 (10) 8 (10) 8 (10) 8

What do we need? We need to determine whether we can "cover" the block like this to eliminate consecutive repeated elements. Here, we placed a "separator" — 10 — between every pair of adjacent 8's.

But if we take the example from the problem statement:
10 5 10 10

The length of the maximum block = 3. Now let's try to cover this block. If we look closely, we cannot cover it because we are missing one more number. If we examine it carefully, in order to cover the longest block of k elements, we need at least k - 1 other elements that will act as separators placed between all adjacent elements of that block, which eliminates consecutive repeats.

So we have the inequality:
n - k >= k - 1

That is: if we occupy k elements as our long block, then to cover it, the remaining elements must be at least k - 1, as we figured out.

Simplifying the inequality gives:
n >= 2k - 1

Great, that's one case. And if we can cover the block, the answer will be sum(a) — because we have eliminated all consecutive duplicates.

BUT

What do we do if we don't have enough elements to cover the block?

Take this example:
7 7 7 7 7 7 3 3 3

As we can see, the maximum block consists of 6 elements, and there are only 3 other elements. How do we compute the sum then?

Let's analyze the optimal arrangement.

First, write out all elements that are not equal to the block element:
3 3 3

Great. Now, we can safely place elements of the block between the 3's and at the edges. In total, there are 4 positions:
7 (3) 7 (3) 7 (3) 7

So we try to cover as much as we can.

And also: we can add one more 7 at the end, and that will count (but any further will not count, because according to the condition, after two consecutive repeats, the boss gains a permanent shield and reflects every subsequent spell):

7 (3) 7 (3) 7 (3) 7 (7)

So the logic here is: we simply try to cover as many as possible, and then add one more element of the block at the end.

Therefore, in this case, the answer will be:
Σ of all elements != el + el * (cnt + 1) + el

which simplifies to:
Σ of all elements != el + el * (cnt + 2)

where el is the block element, and cnt is the length of the maximum block.

Time complexity: O(n)
Space complexity: O(n)
