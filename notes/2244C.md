# Розбір задачі [2244C](https://codeforces.com/problemset/problem/2244/C)

## Ідея:
Загалом задачі на обмін за якоюсь умовою зводяться до графів та DSU тобто множину можливих змін, потім ці множини(компоненти зв'язності) перевіряють з правильними множимани, тобто з тими які мають вийти у кінці
І якщо хоча б із однієї множини ми не можемо зробити правильну відповідну їй множину то ми не можемо наприклад із якогось масива зробити інший масив

В цій задачі ми маємо перестановку яку маємо відсортувати за зростанням, це означає що у кінцевій перестановці має для всіх i (1 <= i <= n) виконуватись наступне:
p[i] = i

Ми можемо переставити деякі елементи за умовою якщо:
|j - i| = x
або
|j - i| = y

Тобто формально ми можемо побудувати граф із n вершин і ребро між якоюсь вершиной і та j буде існувати коли буде виконуватись умова

На приклад візьмемо ось це:
5 2 3
1 2 3 5 4

Тепер питання: як зрозуміти чи ми можемо відсортувати перестановку чи ні?

Побудуємо граф із n вершин:
Для 1 вершини можливі зв'язки будуть з вершинами 3 та 4(тому що |4 - 1| = 3 та |3 - 1| = 2, тобто два можливих варіанта обміну)
Для 2 вершини можливі зв'язки будуть з вершинами 4 та 5(аналогічно як і з 1 вершиною)
Тобто для кожної вершини i зв'язок буде з вершинами i + x(якщо i + x <= n) та i + y(якщо i + y <= n)
Тоді для вершини 3 буде зв'язок тільки з вершиною 5(бо 3 + 3 > 5)

Тобто для цього прикладу ми маємо ось такий граф:
1: 3, 4
2: 5, 4
3: 1, 5
4: 1, 2
5: 3, 2

Тепер візьмемо із цього графа всі його множини(компоненти зв'язності), тобто компонента зв'язності у цьому контектсі це множина всіх обмінів
Наприклад якщо є множина {2, 4, 6} то ми можемо замінити p[2] на p[4], або p[4] на p[6], або p[2] на p[6]

Теперь ключове: коли ми розбили граф на компоненти зв'язності, тобто множини можливих обмінів, нам для кожної множини треба перевірити - чи можливо переставити елементи цієї множини на відповідну їй правильну множину?
Тепер треба зрозуміти, як знайти відповідну правильну множину?
Якщо у правильної перестановки для кожного i -> p[i] = i, тоді множина вершин у графі повинна дорівнювати індексу вершини, тобто якщо у нас є така множина:
{p[a1], p[a2], p[a3], p[a4]} то правильна множина для цієї буде {a1, a2, a3, a4} тобто їх індекси. І якщо для якоїсь множини рівність з правильною не виконується то відповідь NO бо ми не зможемо фізично відсортувати повністю.

## Тому алгоритм:
1. Побудувати DSU
2. Побудувати граф обмінів та знайти всі його компоненти зв'язності(множини обмінівя)
3. Для кожної множини перевірити рівність правильній, якщо десь це не виконується відповідь NO
4. Інакше якщо ми перевірили всі множини і всі вони "правильні" то ми можемо відсортувати за зростанням(відповідно відповідь YES).
