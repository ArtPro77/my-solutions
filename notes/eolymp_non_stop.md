# Non Stop (Eolymp)


## Умова

Скіф дуже любить напій Non Slop, але той швидко закінчується. Тому він регулярно закуповує енергетик ящиками у торговців.

Але нещодавно у торговців оновились ціни: ящик Non Slop-у тепер можна купити лише якщо віддати 1 пару паралельних артефактів.

У зоні всі артефакти пронумеровані від 1 до n. У кожного артефакту є рівень потужності: i-тий артефакт має pᵢ рівень потужності. Пара артефактів з індексами i та j називається паралельною, якщо i < j та pⱼ − pᵢ = j − i.

Скіф хотів би знати, скільки існує різних пар таких паралельних артефактів (i, j), за які можна придбати ящик Non Slop-у.

Примітка: 2 пари артефактів (i₁, j₁) та (i₂, j₂) називаються різними, якщо i₁ ≠ i₂ та j₁ ≠ j₂.

Вхідні дані

У першому рядку знаходиться єдине ціле число n (1 ≤ n ≤ 2⋅10⁵) — кількість артефактів.

У другому рядку знаходяться n цілих чисел p₁, p₂, …, pₙ (1 ≤ pᵢ ≤ n) — потужності артефактів.

Вихідні дані

Виведіть єдине ціле число — кількість пар паралельних артефактів.

Приклади

Вхідні дані #1

3
1 2 3

Відповідь #1

3

Вхідні дані #2

4
1 3 3 4

Відповідь #2

3

Вхідні дані #3

6
3 5 1 4 6 6

Відповідь #3

1

Вхідні дані #4

6
1 6 3 4 5 6

Відповідь #4

10

## Ідея
Перепишемо рівняння:

<pre>
pⱼ − pᵢ = j − i
pⱼ - j = pᵢ - i
</pre>

Що нам це дає?
Спробуємо для кожного i (1 <= i <= n) записати його значення pᵢ - i на цьому прикладі:
<pre>
6
1 6 3 4 5 6

1 -> 1 - 1 = 0
6 -> 6 - 2 = 4
3 -> 3 - 3 = 0
4 -> 4 - 4 = 0
5 -> 5 - 5 = 0
6 -> 6 - 6 = 0
</pre>

Вийшов ось такий масив (нехай буде d):
<pre>
0 4 0 0 0 0
</pre>

## І тепер, ключова ідея: якщо ми візьмемо дві різні позиції, де d[i] = d[j], то це буде наша пара, чому?

Тому що d[i] = p[i] - i та d[j] = p[j] - j

А за умовою, якщо p[i] - i = p[j] - j виконується, то це пара.
Тобто ми можемо взяти будь-які дві позиції, якщо j > i та d[i] = d[j].
І тому задача перетворюється на групування елементів + трохи комбінаторики.

<pre>
Тому ми можемо через map порахувати для елемента (ключа) — кількість разів, коли він зустрічається в масиві (значення)
Для цього прикладу (1 6 3 4 5 6), точніше вже для 0 4 0 0 0 0, map буде ось таким:
4: 1
0: 5
</pre>
Тепер ми маємо пройтись по всім ключам (елементам) цього map і порахувати кількість способів взяти пару, а це порахувати досить легко: $\frac{value*(value-1)}{2}$
Тому ми для кожного елемента рахуємо його $\frac{value*(value-1)}{2}$

і додаємо до відповіді.
Після всіх підсумовувань ми виводимо відповідь.
## Складність за часом: O(n)
