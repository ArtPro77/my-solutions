# Analysis of Problem [2237A](https://codeforces.com/problemset/problem/2237/A)

## Idea:
Of course, this problem can be solved with simulation in O(n^2), by finding for each element the first index with a strictly greater height. The constraints allow an O(n^2) solution.

## BUT!

We will also cover the O(n) optimization. It might be a bit harder to come up with, but here it is:

Let's take an example:
8 7 8 8 9 4 3 1 2

We take the first element (8). We cannot change its height, so we move on. The second element (7) — we cannot change its height either, because it is smaller than the previous one.

Let's recall when we can change a height: only when a[j] > a[i] and j > i. Take the 3rd element (8). Oh, we can change its height, namely to 7 — that's the minimum possible value.

If we replace 8 with 7, we get:
8 7 7 8 9 4 3 1 2

Moving on:
The next element (also 8) can be replaced with the previous 7, giving:
8 7 7 7 9 4 3 1 2

We can also replace 9 with 7:
8 7 7 7 7 4 3 1 2

Moving further, we cannot change 4 because 4 < 7.
So we do nothing and continue:
8 7 7 7 7 4 3 1 2

We also cannot change height 3, since 3 < 4. So we leave it as is. The same goes for 1, since 1 < 3.

Now the last element remains (2). We can change its height to 1, because 1 is the minimum possible:
8 7 7 7 7 4 3 1 1

After performing the operations, we calculate the sum: 8 + 7*4 + 4 + 3 + 2 = 45.

Let's take another example from the problem statement:
6 1 5 2 4 3

We cannot change the first element, nor the second.
But we can change 5 to 1:
6 1 1 2 4 3

Then change 2 to 1:
6 1 1 1 4 3

Then change 4 to 1:
6 1 1 1 1 3

And change 3 to 1:
6 1 1 1 1 1

## The key idea here is:
if we find a minimum value on some segment, we can change other elements to this minimum if the condition holds: a[i] > mn, where mn is the current minimum.

And if we find an element < mn (i.e., even smaller), we essentially update the minimum — mn = a[i] — we immediately add it to the sum without changing anything else.

Now the problem reduces to a single pass. The minimum starts at a[0]. We iterate with a for loop, and if some element is greater than the minimum, we replace it with that minimum. Otherwise, we update the minimum (make it even smaller).

And we calculate the final sum on the fly.

Time complexity: O(n)
